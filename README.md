# Guide Pas à Pas : SAP Fiori & MM (Materials Management)

Ce dépôt contient un guide complet pour apprendre à créer des applications Fiori transactionnelles sur SAP S/4HANA (OData V2 / BOPF).

## Sommaire
1.  **[Guide d'Introduction (Débutant)](./SCENARIO_MM_FIORI.md)** : Apprenez à installer les outils et à créer votre première application de Demande d'Achat simple.
2.  **[Projet Complet - 1 Semaine (Avancé)](./PROJET_MM_FIORI_FULL.md)** : Un curriculum détaillé pour maîtriser la logique métier complexe (Validations, Actions, Analytics).
3.  **[Code Source du Projet](./PROJET_MM_COMPLET/)** : Tous les fichiers ABAP, CDS et UI organisés par dossier.

## Technologies utilisées
- **ABAP CDS Views** (Core Data Services)
- **BOPF** (Business Object Processing Framework) pour le transactionnel
- **OData V2** (Auto-publish)
- **SAP Fiori Elements**
- **Module SAP MM** (Purchase Requisitions / Demandes d'Achat)
